# تقرير تنفيذ الإعدادات المركزية ولوحة المطور

اكتمل ربط إعدادات الهوية والمظهر والتشغيل الآمن بقاعدة البيانات وLaravel وReact والتقارير. لم تتغير معادلات المخالصات والإجازات ونهاية الخدمة أو أرصدة السلف ضمن هذه المهمة. بدأ العمل بتوثيق الوضع السابق في `SYSTEM_CONFIGURATION_AUDIT.md`.

## الملفات الجديدة

- `config/system.php`: سجل الإعدادات وقيمها الافتراضية وقواعد التحقق.
- `database/migrations/2026_10_22_000003_create_system_settings.php`: جدولا الإعدادات وأصول الهوية.
- `app/Models/SystemSetting.php`، `app/Services/SystemSettingsService.php`: التخزين والقراءة والتنسيق وCache والتحقق والتدقيق وتعارض نسخ الحفظ.
- `app/Policies/SystemSettingPolicy.php`، `app/Http/Middleware/AuthorizeDeveloper.php`: حماية دور المطور وصلاحيته.
- `app/Http/Controllers/Api/SystemSettingsController.php`: APIs القراءة والحفظ والاستعادة والتصدير والرفع والفحص والتدقيق.
- `app/Console/Commands/CreateDeveloper.php`: إنشاء المطور تفاعليًا.
- `app/Listeners/ApplySystemMailBranding.php`: اسم المرسل المركزي دون تغيير عنوان البريد.
- `resources/views/vendor/mail/html/header.blade.php` و`footer.blade.php`: هوية قوالب البريد.
- `resources/views/system-home.blade.php` و`resources/views/exports/branding-style.blade.php`: الصفحة الخلفية وألوان التقارير.
- `frontend/src/system/settings.js` و`SystemSettingsContext.js` و`SystemSettingsProvider.jsx` و`Brand.jsx` و`system.css`: مصدر الهوية في الواجهة والمتغيرات المرئية والمعاينة.
- `frontend/src/pages/DeveloperSettingsPage.jsx`: لوحة المطور.
- `scripts/serve-local.ps1`: تشغيل PHP المحلي مع مجلد رفع صالح وسجل أخطاء مستقل.
- `tests/Feature/SystemSettingsTest.php` و`tests/Fixtures/prepare_settings_e2e.php` و`frontend/e2e/system-settings.spec.js`: اختبارات الخلفية والمتصفح وحساب اختبار معزول.
- `docs/SYSTEM_CONFIGURATION_AUDIT.md` و`docs/SYSTEM_CONFIGURATION.md` و`docs/DEVELOPMENT_STANDARDS.md` وهذا التقرير.

## قاعدة البيانات والإعدادات

`system_settings` يحفظ `scope/group/key/value(JSON)/value_type/is_public/is_editable/updated_by/timestamps` مع مفتاح فريد `scope,key`. صف داخلي محمي يحفظ `revision` لمنع الكتابة فوق تعديل أحدث. `system_branding_assets` يحفظ UUID والمسار الخاص وبصمة الملف ومن رفعه. تم تطبيق الترحيل المحلي.

المجموعات المتاحة: أسماء النظام والشركة والتذييل والموقع والشعارات؛ الألوان والخطوط والحواف والوضع الفاتح والداكن وكثافة الجداول؛ تنسيق التاريخ والأرقام والمنطقة الزمنية وصفوف الجداول ودقة عرض المال؛ بادئات المستندات؛ وهوية التقارير والورق والاتجاه والتذييل. المرجع التفصيلي في `SYSTEM_CONFIGURATION.md` والسجل الفعلي في `config/system.php`.

الحفظ يتطلب سببًا، وتُسجّل القيم السابقة والجديدة. الاستعادة والتصدير مقيدان بالقائمة المعتمدة. لا توجد أسرار اتصال أو قواعد مالية قابلة للتغيير من اللوحة. تُزال الذاكرة المؤقتة بعد نجاح المعاملة. الشعارات تعاد كتابتها كصور PNG وتُرفض SVG والملفات التنفيذية.

## إنشاء حساب المطور والوصول

من مجلد المشروع:

```powershell
php artisan developer:create
```

أدخل الاسم والبريد وكلمة المرور وتأكيدها. الحد الأدنى 12 حرفًا، ولا تُطبع كلمة المرور أو تسجل. لم يُنشأ حساب مطور تشغيلي بكلمة مرور افتراضية؛ حساب الاختبار موجود في قاعدة اختبار منفصلة فقط.

سجل الدخول بالحساب ثم افتح «إعدادات المطور»، أو `http://127.0.0.1:5173/#/developer/settings`. المدير العادي لا يمنح نفسه هذه الصلاحية، ولا يستطيع إدارة حساب المطور من شاشة المستخدمين.

## التحقق

- Laravel: **210 اختبارات ناجحة و1399 تحققًا**، تشمل صلاحيات APIs والتلاعب بالطلبات والملفات والقيم المحمية وCache والتقارير والحسابات القائمة.
- بناء React للإنتاج: ناجح.
- فحص الواجهة Oxlint: دون أخطاء؛ بقي تحذيران سابقان في effect داخل `TransactionDetailsPage.jsx`، خارج نطاق لوحة الإعدادات.
- اختبار لوحة المطور الحقيقي عبر HTTP: نجح تغيير الاسم واللون ورفع الشعار، والوضع الداكن والمعاينة والإلغاء والحفظ وإعادة التحميل والاستعادة ومنع المدير العادي.
- اختبارات المتصفح الشاملة: **17 اختبارًا ناجحًا** في تشغيل معزول واحد، تشمل الموظفين والاستيراد والتصفية التجريبية والمخالصات والإجازات والمراجعة والتعديلات والتصدير والطباعة والسلف والترحيل المالي وإدارة البيانات والمستخدمين ولوحة المطور.

اختبارات المتصفح تستخدم قواعد وخدمات اختبار مستقلة عن قاعدة التشغيل. النسخة الاحتياطية السابقة للترحيل: `storage/app/backups/settlement-20261022-103221-4bc423d8a577.zip`.

## القيود المعروفة

- تخصيص على مستوى تثبيت واحد باستخدام scope قابل للتوسع؛ لم يُنفذ تعدد الجهات.
- النصوص الحالية عربية؛ اختيار الإنجليزية يضبط الاتجاه والتنسيق ولا يترجم جميع نصوص الأعمال.
- العملة SAR فقط، والمنازل العشرية للعرض دون تعديل المبالغ المخزنة.
- PDF يستخدم خطوطه المدمجة الداعمة للعربية، وليس كل خط متاح في المتصفح.
- JSON الإعدادات يحفظ مراجع الشعارات داخل التثبيت نفسه. النقل لتثبيت آخر يحتاج رفع الشعارات هناك أو استخدام النسخة الكاملة التي تشمل الملفات.
- فحص البريد لا يرسل رسالة ولا يكشف إعدادات SMTP؛ قوالب الهوية جاهزة للاستخدام عند الإرسال.
- تبقى أصول الشعارات السابقة محفوظة؛ لا يوجد حذف تلقائي قد يكسر مرجعًا مستخدمًا.

قواعد إضافة أي إعداد أو شاشة جديدة موثقة في `DEVELOPMENT_STANDARDS.md`.
